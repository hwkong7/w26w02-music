# 2026 웹서버프로그래밍 — 유튜브뮤직 만들기

Week 02 실습 주제는 원래 멜론 차트였지만, 평소에 쓰는 유튜브뮤직 스타일로 바꿔서 만들어봤습니다. 검은 배경과 빨간 포인트 컬러의 다크 테마 뮤직 플레이어 UI로, 카드/리스트 형태로 곡을 보여주고 클릭하면 유튜브 노래방 검색 결과로 연결됩니다.

## 주요 기능

- **카테고리 칩**: 전체 / 운동 / 집중 / 기분 전환 / 출퇴근 필터 버튼 (UI만 구현)
- **빠른 선곡**: 앨범 카드 그리드
- **인기 차트**: 순위가 매겨진 트랙 리스트
- **검색**: 검색창에 입력하면 곡명/아티스트 기준으로 카드·트랙 목록이 실시간 필터링됨
- **하단 플레이어 바**: 현재 재생 곡 정보와 컨트롤 UI (정적 표시)

## 파일 구성

```
index.html   페이지 구조
style.css    스타일 (다크 테마, 반응형)
script.js    검색 필터링 기능
```

## 배포

GitHub Pages로 배포합니다.

## 기술 스택

- HTML5 / CSS3
- Vanilla JavaScript (검색 필터링)
